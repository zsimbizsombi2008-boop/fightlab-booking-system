# FightLab Booking System

Martial arts booking system built as a full-stack learning project.

## Features

- Users can choose a sport and book a session
- Booking data is handled by a Node.js / Express backend
- MySQL database storage
- Email confirmation after booking
- Admin interface for managing bookings
- Input validation and error handling

## Tech stack

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL
- Nodemailer / Brevo
